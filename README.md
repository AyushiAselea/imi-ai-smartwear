# IMI AI Smartwear

Product landing page and shop frontend for IMI smartwear.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting started

Requires Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
# Install dependencies
npm i

# Start the dev server at http://localhost:8080
npm run dev
```

## Scripts

```sh
npm run dev          # Start dev server at http://localhost:8080
npm run build        # Production build
npm run build:dev    # Development build (no optimization)
npm run lint         # Run ESLint
npm run test         # Run tests (Vitest) once
npm run test:watch   # Run tests in watch mode
npm run preview      # Preview production build locally
```

## Deployment

Build with `npm run build` and serve the generated `dist/` directory from any
static host.
